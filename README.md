## Design Philosophy

The website follows a modern, premium aesthetic with:
- **Dark theme** for reduced eye strain and modern appeal
- **Gradient accents** (orange to blue) for brand identity
- **Consistent interactions** - all cards and buttons share hover effects
- **Typography** - Inter font family for clean, professional readability
- **Accessibility** - semantic HTML, focus states, skip links
